## 🚀 Proyecto destacado: AGX Notes
Una **app de cuadernos para programadores que funciona sin internet**, hecha para tablets Android.
- Editor de texto enriquecido con **bloques de código con resaltado de sintaxis** (14 lenguajes)
- Búsqueda de texto completo con **SQLite + FTS5** y respaldo/restauración en JSON
- Funciona en dispositivos **sin servicios de Google** (HarmonyOS)
- Español / inglés, temas claro y oscuro
- Arranque optimizado de 6,6 s a **2,7 s**

`React Native` `Expo` `TypeScript` `SQLite` `Tiptap` `Android`
